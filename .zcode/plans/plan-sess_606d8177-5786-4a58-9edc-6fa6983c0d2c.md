### Architecture (request → background → poll)

```
POST /submit
  ├─ finalize txn (unchanged) + writes diagnosticStatus:"pending"      ┐
  ├─ HTTP response returns immediately with deterministic grade         │ does NOT block
  └─ after(() => runDiagnosticPipeline(id))  ← next/server, Node runtime┘
        ├─ re-read attempt (grade, answers, transcripts, examId)
        ├─ assemble Evidence Bundle (micro-skills from station.kind, signals from dwell-time percentiles)
        ├─ Examiner Agent (gpt-4o-mini) → Zod-validate (≤3 tries) → report
        ├─ Validator Agent (gpt-4o-mini) → Zod-validate (≤3 tries) → validated report
        └─ Firestore write: diagnosticStatus:"ready" + diagnosticReport  (or "error" on exhaustion)

ResultsView polls GET /api/test-attempts/[id] every 5s
  pending → loading card · ready → raw JSON render · error → graceful fallback · absent → deterministic only
```

### New files (4) — all in `src/lib/ai/`

**1. `src/lib/ai/diagnostic-schema.ts`** — Zod mirror of the approved JSON schema (sections C of the plan), verbatim structure: `summary{headline,overview}`, `strengths[]`, `emergingPatterns[]`, `criticalWeaknesses[]{severity:"high"|"medium"|"low"}`, `rootCause{diagnosis,linkedWeaknesses[]}`, `actionPlan[]{step,title,detail,targets[]}`. Exports `DiagnosticReportSchema` + inferred `DiagnosticReport` type. Imported by grader + attempt-types.

**2. `src/lib/ai/prompts.ts`** — `EXAMINER_SYSTEM_PROMPT` + `VALIDATOR_SYSTEM_PROMPT`, copied **verbatim** from the approved plan (sections D, E). Untouched, as you directed.

**3. `src/lib/ai/evidence-bundle.ts`** — `assembleEvidenceBundle(exam, attempt)`:
- `MICRO_SKILL_BY_KIND` lookup table (14 station kinds → human label, e.g. `proof → "True / False / Not Given with evidence location"`, `cueCard → "extended narrative fluency (Part 2 cue card)"`). No micro-skill field exists on questions, so derived from `station.kind`.
- `items[]`: deterministic questions (reading/listening/cohesion). Each carries `stationId, questionId, kind, microSkill, prompt, studentAnswer, correctAnswer, behavioral{timeSpentMs}, signals{isCorrect, proofMechanicFailure, luckyGuess, slowAndWrong, fastAndWrong}`.
  - `isCorrect` ← read from `grade.stations[].perQuestion[key]` (already computed by deterministic grader).
  - `proofMechanicFailure` ← tfng only: verdict matches but `proofSentenceIndex` doesn't (fragile knowledge).
  - **Dwell time** ← `lockedAt - firstSeenAt` per question (`timeSpentMs` is never populated — always 0 — so I derive from the two timestamps that *are* reliably set).
  - **Percentile signals** (25th/75th of that attempt's per-station dwell times): `luckyGuess = correct ∧ fast ∧ no proof-failure`; `slowAndWrong`; `fastAndWrong`. If dwell times are all 0/missing → time signals degrade to false (never invented).
- `writingResponses[]`: paraphrase/bodyParagraph text + prompt + wordCount.
- `speakingTranscripts[]`: from `attempt.transcripts[key]` + task description.
- `globalMetrics`: `tabSwitchCount`, `totalActiveTimeMs` (completedAt − startedAt), `budgetedTimeMs` (exam.durationSeconds).

**4. `src/lib/ai/grader.ts`** — the AI Grading Service (the file you named). Exports `runDiagnosticPipeline(attemptId: string): Promise<void>`:
- Guard: bail if `diagnosticStatus !== "pending"` (handles re-entry / double-fire).
- Construct OpenAI client per call (mirrors `whisper.ts` pattern, `getApiKey()` guard on `OPENAI_API_KEY`).
- **Examiner**: `client.chat.completions.parse({ model:"gpt-4o-mini", messages:[{role:system, content: EXAMINER_SYSTEM_PROMPT},{role:user, content: JSON.stringify(bundle)}], response_format: zodResponseFormat(DiagnosticReportSchema,"report") })`. Zod `safeParse` the output; **retry up to 3×** on parse failure.
- **Validator**: same call shape, system prompt = `VALIDATOR_SYSTEM_PROMPT`, user content = `{report, bundle}`. Retry ≤3×.
- Success → `update({ diagnosticStatus:"ready", diagnosticReport, diagnosticGeneratedAt:serverTimestamp() })`.
- Exhaustion/failure → `update({ diagnosticStatus:"error", diagnosticError: msg })`. Logs with `[diagnostic]` prefix.
- Every step wrapped in try/catch; the outer catch always writes `"error"` so no student is stuck pending forever.
